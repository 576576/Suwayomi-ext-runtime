## 维护约定

- 已定的选型**连日期一起留着**（「已定（YYYY-MM-DD）」），它是后来者判断「能不能改回去」的唯一依据。
- 落地之后**不删文档**：把结果补成一节（「落地情况」），否则下一个人会照着已失效的前提再推一遍。
- 与代码现状对不上的口径当场改掉 —— 计划里的过时事实比没有文档更糟。

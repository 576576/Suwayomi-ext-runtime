## 维护约定

- **只写「是什么」和「不这么做会怎么错」**。决策过程与试错史留在 commit message 里，不进这里 ——
  文档里出现「此前是…」「当初踩过…」这类叙述，说明该删了。
- 这里是**约定与契约**：改了行为就同步改。一次性调研、审计报告、施工进度记录不进这里。
- 代码里放不下的**理由**写到这里；代码注释只留结论。
